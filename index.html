LOG-00 · Jun 2026–Present Open Source · Actively Maintained

FastAgent

A hardware-adaptive local LLM inference orchestrator that runs autonomous ReAct agents on CPU-only, 8 GB RAM devices. Naive local agent loops re-evaluate the system prompt every turn and let context grow until memory runs out. FastAgent wraps the llama.cpp server with Longest Common Prefix slot caching, 8-bit KV-cache quantization, rolling context windows, GBNF grammar-constrained decoding that forces valid JSON even from sub-3B models, and an Adaptive Compute Controller that scales token budgets and temperature by prompt complexity. It registers Python functions as tools and handles system prompts and tool routing itself.
