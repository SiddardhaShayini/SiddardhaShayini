### 🚀 Featured Projects

* ⚡ **[FastAgent](https://github.com/SiddardhaShayini/Optimizing-Local-AI-Agents):** A hardware-adaptive local LLM inference orchestrator that runs ReAct agents on CPU-only, 8 GB RAM devices. Combines LCP prefix caching, 8-bit KV-cache quantization, and grammar-constrained decoding to cut prompt latency from **~3,500 ms to ~73 ms** with **zero OOM crashes**. *(Open Source, MIT)*
* 🐾 **[WildGuardAI](https://github.com/SiddardhaShayini/WildGuardAI-Real-Time-Wildlife-Conflict-Prediction):** Real-time wildlife conflict prediction system powered by YOLOv12n, BoT-SORT, and a Kalman Filter *(IEEE Xplore Published, 2026)*.
* 🧓 **[JivanMitra](https://github.com/SiddardhaShayini/JivanMitra---Offline-First-Intelligent-AI-Assistant-using-RAG-Agents):** An offline-first, voice-enabled AI companion for elders using LangChain, RAG, and agentic AI.
* 🔒 **[Personal AI Agent](https://github.com/SiddardhaShayini/Personal-AI-Agent):** A local-first, privacy-focused AI assistant built with Ollama and LanceDB.
* 📚 **[Offline Deep Research Agent](https://github.com/SiddardhaShayini/Offline-Deep-Research-Agent-using-Ollama-Mistral-and-LangChain):** A research agent that reasons over documents entirely offline, using Ollama, Mistral, and LangChain.
